Punch List Documentation App

A web/tablet application for architectural and engineering punch list inspections. Users upload PDF drawings, pin punch items to exact locations on the plan, attach photos and comments, assign items to team members, track status, and export the marked-up drawing as a shareable PDF.

Course: CMSC 447 — Software Engineering I, Fall 2026
Team: Fawaz Shaikh, Joey, Saumya
Stack: React + pdf.js · [backend] · PostgreSQL · AWS (S3, RDS)
